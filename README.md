# clackmere-site

Landing page, privacy policy and support page for **Clackmere**, an offline stone-sliding puzzle for iPhone.

Live at https://nguyenvanlamm.github.io/clackmere-site/ (GitHub Pages, served from `main`, no build step).

- `index.html` — the landing page
- `privacy.html` — the App Store privacy policy URL
- `support.html` — the App Store support URL
- `assets/` — screenshots made from the game's own screens, its icon, and its OFL fonts (Figtree, Outfit; licences in
  `assets/fonts/`)

Every push to `main` republishes the site.
